# Teknoloji Seçimi (Tech Stack) - HearMe Uygulaması

* **Frontend (Arayüz):** HTML, CSS ve JavaScript (Vanilla JS). Başlangıç seviyesi için en basit teknoloji yığını olduğu ve hızlıca şekillendirilebildiği için seçildi.
* **Ses İşleme (Speech-to-Text & Text-to-Speech):** Tarayıcıların yerleşik Web Speech API özelliği. Ekstra paket kurulumu gerektirmediği için prototipi 10 günde yetiştirmek adına en pratik çözümdür.
* **Yapay Zeka (AI):** Google AI Studio üzerinden Gemini API. Uygulama içindeki "Akıllı Hazır Cevaplar" butonlarının içeriğini yönetmek ve konuşmanın gidişatına göre tahminlerde bulunmak için kullanılacak.
* **Yayınlama (Deploy):** Lovable. Ücretsiz olduğu ve GitHub ile saniyeler içinde entegre olup tek tıkla canlıya alabildiği için tercih edildi.
